GLM Distribution Explorer

For people who use R but are not sure which GLM distribution to try. You do not need to know the formulas.

In short: load a CSV, check the suggested roles, run, look at ΔAIC and the Q-Q plots, then copy the code of the model you want to work on.

1. Check the shape of your data

The app expects one row per observation. If each person answered several items, each answer is its own row (long format):

participantconditionrt
P01A512
P01B634
P02A478

If items are spread over columns, the app usually notices and offers a "Convert to long" button. In Excel, use Save As → CSV UTF-8.

2. Check the roles

Roles are suggested automatically. These questions help you check them:

QuestionRole
What did I measure?Y (outcome), one column
What do I expect to influence it? Is it a group or condition?X categorical
Is it an amount, such as age?X numeric
Did the same person, class or item appear several times?Random effect for that ID column
Did observation time or opportunity differ between rows, for a count Y?Exposure
Row numbers, memos, dates, other outcomesNot used

The one to look at twice: if the same person answered more than once and the ID is not a random effect, p-values tend to come out too small.

3. Check the type of Y

What Y looks likeTypeDistributions compared
Reaction time, cost (always above 0)Positive continuousGaussian, Gamma, Lognormal …
Spending with many zerosNon-negative with zerosTweedie, Hurdle …
Difference scores (can be negative)Real-valuedGaussian, Student t …
Number of errors (0, 1, 2 …)CountPoisson, negative binomial …
Proportion such as 0.37 with no known totalProportionBeta …
Right/wrong, yes/noBinaryBinomial (links are compared)
14 correct out of 20Successes / trialsBinomial, Beta-binomial
A single 1-5 or 1-7 ratingOrdinalCumulative models (links are compared)

Milliseconds stored as whole numbers are still a time, so "Positive continuous" usually suits them.

4. Run and look at two things

  1. ΔAIC: 0 is the best of this list. Up to 2 is practically a tie.
  2. Diagnostics: ✓, △ or ✕. A low ΔAIC with ✕ means "best of the list, but still does not fit well".

AICc, BIC and the rest can wait until you need them.

5. Read the Q-Q plots

Points on the diagonal are good. The gray band is what chance allows. Both ends often drift a little, so start with the middle.

6. If it is a tie, or nothing fits

  • Tie: the one that is common in your field or easier to explain is a reasonable choice.
  • Nothing fits: look for a forgotten ID, a missing X, typing errors or extreme values in Y, or a curved relationship.
  • Did not converge: try standardizing numeric X, dropping the random slope, or using fewer X.

7. Put the coefficients into words

After "Choose this" you see a table. For a categorical X, each row compares one level with the reference level (the alphabetically first).

ModelExampleIn words
GaussianconditionB estimate 72B is 72 units higher than A on average
Gamma, Poisson, NB (log)conditionB exp 1.13The mean for B is about 1.13 times A (13% higher)
LognormalconditionB exp 1.13The geometric mean for B is about 1.13 times A
Binomial (logit)conditionB exp 2.0The odds for B are about twice those for A (not "twice as likely")
Ordinal (logit)uinew estimate 0.9"new" shifts answers toward higher categories; exp(0.9) ≈ 2.5 is an odds ratio
  • If the 95% interval excludes 0 (or 1 for exp), the data are hard to reconcile with "no difference". If it includes it, that is not proof of no difference.
  • With random effects, log- and logit-link effects describe comparisons at the same random-effect level (for example the same person).
  • With interactions, a single row no longer means "the overall effect".
  • With Gamma (inverse), a positive coefficient means a lower mean.

8. Use the code in R

  1. Put the CSV in your R project folder. If you converted the data, use "Save this data as CSV".
  2. Run the install.packages line once.
  3. Paste the code and run it line by line.
MessageUsually means
cannot open fileThe working folder is different. Check getwd().
there is no package calledThe install line has not been run.
object 'm' not foundAn earlier line failed. Run again from the top.

The code is a starting point: adapt X, interactions and random effects to your design.

9. Words you will meet

DistributionHow Y scatters around its predicted value
LinkThe scale on which X is added up. With log, effects are multiplications
Random effectLets each person or group have its own level
OverdispersionMore spread than the distribution expects
Zero-inflated, HurdleModels with a separate part for zeros
ResidualThe gap between observed and predicted; here transformed so a good model gives a straight Q-Q line
ConvergeThe calculation settled on an answer
SingularA random effect is too small or complex to estimate from these data

R은 사용하지만 GLM에서 어떤 분포를 써볼지 막막한 분들을 위한 안내입니다. 수식을 몰라도 보실 수 있습니다.

한눈에 보기: CSV를 올리고, 추천된 역할을 확인하고, 실행한 뒤 ΔAIC와 Q-Q 플롯을 봅니다. 그다음 작업할 모델의 코드를 복사하시면 됩니다.

1. 데이터 모양 확인

한 행에 관측 하나를 기준으로 합니다. 한 사람이 여러 번 답했다면 답 하나가 한 행이 됩니다(long 형식).

participantconditionrt
P01A512
P01B634
P02A478

문항이 여러 열로 펼쳐져 있으면 앱이 대체로 알아차리고 "long 형식으로 바꾸기" 버튼을 보여줍니다. 엑셀에서는 다른 이름으로 저장 → CSV UTF-8을 고르시면 됩니다.

2. 역할 확인

역할은 자동으로 추천됩니다. 아래 표로 맞는지 확인하실 수 있습니다.

열의 내용역할
측정한 결과Y (결과), 열 하나
Y에 영향을 줄 것으로 보는 집단이나 조건X 범주
나이처럼 크기가 있는 값X 수치
여러 번 나오는 사람, 학급, 문항의 ID랜덤효과
횟수를 셌고 행마다 다른 관찰 시간이나 기회노출량
행 번호, 메모, 날짜, 다른 결과 변수사용 안 함

한 번 더 볼 부분: 같은 사람이 여러 번 답했는데 ID가 랜덤효과에 없으면 p값이 실제보다 작게 나오기 쉽습니다.

3. Y 유형 확인

Y의 모습유형비교하는 분포
반응시간, 비용 (항상 0보다 큼)양수 연속Gaussian, Gamma, Lognormal 등
0이 많은 지출액0 포함 양수 연속Tweedie, Hurdle 등
차이 점수 (음수 가능)실수 연속Gaussian, Student t 등
오류 개수 (0, 1, 2 …)카운트Poisson, 음이항 등
전체 개수를 모르는 0.37 같은 비율비율Beta 등
맞음/틀림, 예/아니요이분형Binomial (링크 비교)
20문제 중 14개 정답성공 수/시행 수Binomial, Beta-binomial
1~5점, 1~7점 응답 하나순서형누적 모형 (링크 비교)

밀리초가 정수로 저장되어 있어도 시간이므로 보통 "양수 연속"이 어울립니다.

4. 실행한 뒤 두 가지 보기

  1. ΔAIC: 0이 후보 중 가장 좋은 값이고, 2까지는 사실상 동률입니다.
  2. 진단: ✓, △, ✕로 표시됩니다. ΔAIC가 낮은데 ✕라면 "후보 중에는 낫지만 잘 맞지는 않을 수 있다"는 뜻입니다.

AICc, BIC 등은 필요할 때 보셔도 됩니다.

5. Q-Q 플롯 읽기

점이 대각선에 붙어 있을수록 좋습니다. 회색 띠는 우연히 벗어날 수 있는 범위입니다. 양 끝은 조금 벗어나는 일이 흔하므로 가운데부터 보시면 됩니다.

6. 동률이거나 맞는 분포가 없을 때

  • 동률: 분야에서 흔히 쓰거나 설명하기 쉬운 쪽도 무난한 선택입니다.
  • 맞는 분포가 없을 때: 빠뜨린 ID, 빠진 X, Y의 입력 오류나 극단값, 곡선 관계가 있는지 살펴보실 수 있습니다.
  • 수렴하지 않을 때: 수치 X 표준화, 랜덤 기울기 빼기, X 줄이기를 시도해 보실 수 있습니다.

7. 계수를 말로 풀기

"이 분포로 확정"을 누르면 표가 나옵니다. 범주 X의 각 행은 기준 수준(알파벳순 첫 번째)과 비교한 값입니다.

모델예말로 풀면
GaussianconditionB 추정치 72B가 A보다 평균 72만큼 높음
Gamma, Poisson, NB (log)conditionB exp 1.13B의 평균이 A의 약 1.13배 (13% 높음)
LognormalconditionB exp 1.13B의 기하평균이 A의 약 1.13배
Binomial (logit)conditionB exp 2.0B의 오즈가 A의 약 2배 ("확률이 2배"와는 다름)
순서형 (logit)uinew 추정치 0.9new에서 더 높은 점수 쪽으로 이동, exp(0.9) ≈ 2.5는 오즈비
  • 95% 구간에 0(exp는 1)이 없으면 "차이 없음"으로 설명하기 어려운 데이터입니다. 포함되더라도 차이가 없다는 증거로 보기는 어렵습니다.
  • 랜덤효과가 있으면 로그, 로짓 링크의 효과는 랜덤효과 수준이 같을 때(예: 같은 사람)의 비교입니다.
  • 교호작용이 있으면 한 행만으로 전체 효과를 말하기 어렵습니다.
  • Gamma (inverse)에서는 계수가 양수이면 평균이 낮다는 뜻입니다.
